# 👋 Hi, I'm Tsedenya Emkedemealem

**Software Engineer | Backend Developer | AI Enthusiast**

I like taking software from idea to production, but where I really live is the backend — designing APIs, structuring databases, and getting the logic right under the hood. My day-to-day toolkit is Spring Boot and Python, with some Node.js when a project calls for it, plus enough frontend know-how (React, Vue.js) to ship a feature end to end when needed. What actually gets me excited these days is AI — training models, building chatbots, and figuring out how to fold that into real backend systems rather than treating it as a bolt-on. I've built ERP systems, client-facing platforms, and worked on plenty of team projects along the way.

### [IPv6 Ethiopia](https://myportfolio-pi-one.vercel.app/)
A national internet infrastructure portal supporting Ethiopia's transition to advanced network standards. Live, cloud-hosted, and currently supporting national network-awareness initiatives across the country.

### [ETNERD – Ethiopian Network of Researchers & Developers](https://myportfolio-pi-one.vercel.app/)
The primary web platform for the national tech ecosystem, with a custom admin dashboard. Live and fully managed in the cloud, providing a reliable resource for researchers across the country.
